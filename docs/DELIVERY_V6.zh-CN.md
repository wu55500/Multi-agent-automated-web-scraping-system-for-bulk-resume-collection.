## 1. 验收标准

“100% 实现”是指明确界定范围内的每项需求均具有实现、可复现测试、部署证据及已验收的运行指标。单元测试通过不等于生产就绪、通用 ATS 兼容、投递成功或市场覆盖达标。本轮未向企业投递简历或发送 HR 消息。

## 5. 访问与凭据

`127.0.0.1:8771` 指向打开浏览器的设备。在手机上访问，要求服务运行在该手机上。拒绝连接不能据此判定 VPN 故障或 OpenAI 屏蔽。在同一设备执行 `python scripts/start_local.py`，或使用 `OPERATIONS_V6.md` 中核验过的 Railway HTTPS 地址。

Railway Variables 中的 `DZ_ACCESS_TOKEN` 可显示并复制到看板 Token 输入框。它不是 OpenAI API key。`DZ_DATABASE_URL` 引用私网数据库。禁止提交凭据。模型配置见 `examples/models.json`；替换占位 endpoint/model，并配置指定环境密钥。不要将 API key 粘贴到公开 issue 或代码中。

GitHub 管理源码/历史/CI；Railway 托管运行服务/数据库；OpenAI Developers 可辅助 API 集成，但不会自动授予有余额的 API 访问权限。未确认提示来自哪个服务前，不能把“工作用量”提示归因于 Railway。
